This is an interesting exercise in [Literate Programming](https://en.wikipedia.org/wiki/Literate_programming) and the [ZX](https://google.github.io/zx/) tool from Google.

This is similar to using [Jupyter notebooks](https://jupyter.org/) with the [Bash Kernel](https://github.com/takluyver/bash_kernel).

ZX uses Node to run the scripts and it the [Bash shell](https://www.gnu.org/software/bash/) under the hood.

The one downside of using ZX is that it requires a full, and different, API
